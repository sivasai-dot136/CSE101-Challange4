# CSE101-Challange4
Start
Set all counts and totals to 0.
Enter an expense.
If expense is 0, stop.
If expense is negative, print Invalid expense and enter again.
Add the valid expense to the total and increase the count.
Check the expense:
Less than 100 → Small
100 to 499 → Medium
500 or more → Large
Increase the corresponding count and total.
Repeat from Step 3.
Print all counts, totals, and the average expense.
Stop.
